# WFL-Net
WFL-Net: Residual graph attention network for wheat flag leaf segmentation from 3D point clouds. Achieves 84.30% mIoU on 1,460 samples. Introduces Point Group Attention Module (PGAM) and Feature Fusion Attention Module (FFAM) with Focal-Dice loss. Converges in 20 epochs, outperforming PointNet++, DGCNN, Point Transformer.
